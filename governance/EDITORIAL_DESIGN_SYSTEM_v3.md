# ServiceStack / AffiliateOS — Premium Editorial Design System v3.0
Adopted: November 12, 2026. The highest-priority visual standard for all existing and future AffiliateOS media sites.
Distinct original editorial identity; inspiration is premium business publishing, not copying Forbes, Financial Times or any publication logo, page or trademark.

## Visual identity
Black/white business newspaper architecture, cultured large Georgia serif titles and system sans-serif reading copy. Strong masthead, quiet byline, disciplined composition, editor-first image selection and text readability. Solid ink #161719, paper #fdfcf9, restrained deep red #9e302f, rule #d9d7d2. Each future vertical may change wordmark and accent but keeps this design language.
- Main reading column <= 770 px, 18px desktop body with line-height ~1.78; 17px mobile.
- 34px side paddings on large screens, 20px on mobile. Header and section spacing follow a 8/16/24/32/48/64/80px rhythm.
- Site homepage: masthead -> featured topical story -> research desk -> practical original tools -> editorial method -> transparent footer.
- Article: category -> substantial headline/dek -> honest source/date/disclosure -> relevant image and provenance caption -> evidence-grounded body -> tool/table where meaningful -> sources and linked follow-up.
- Use real permitted photos or original labeled synthetic editorial images (never presented as actual client projects); avoid giant fake dashboard graphics, icons-as-content, repetitive cards, gradients and fake reviews.
- No external paid fonts or assets. Accessibility: semantic heading/nav, focus-visible, alt text, useful contrast, keyboard tools, no horizontal whole-page overflow.
- Check 390/768/1280/1440px and real GitHub Pages deployment; internal links, responsive tables, images, JS and captions; CI static success is not complete independent QA.

## Design maintenance
One shared canonical stylesheet: assets/editorial.css. No independent inline article CSS. New sites get a theme variant via design tokens, never a fresh generic template. Avoid duplicating photo assets across cards unless actual editorial need.
Commit design and page changes together. Independently QA all changed pages before removing staging noindex. No paid resources before first actual partner payout and owner reinvestment approval.
